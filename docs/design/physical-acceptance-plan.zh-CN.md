# M9/M10 物理验收前置条件（未执行）

日期：2026-11-15
状态：计划文档；**当前没有真实硬件、工业场地或外部专家，M9/M10 未执行**

## 1. 为什么单独记录

Poieweave 的 S1–S4 证据全部是模型级/软件级。即使 S1–S4 全部通过，也不能推出：

- 真实设备寿命
- 工业安全性
- 阀门/泵/机器人不会卡滞
- 现场网络与时钟行为
- 法规或合同层面的可接受性

因此 M9/M10 必须保持为独立的外部验收门槛，不能被 S1–S4 替代。

## 2. 最小物理试验台

| 组件 | 最低要求 |
| --- | --- |
| 水泵 | 可重复启停，带可测流量/压力 |
| 储能 | 可测 SOC/功率，具备过充过放保护 |
| 维修执行器 | 机器人或人工执行，可记录动作与时间 |
| 备件/耗材 | 可计量，可人为耗尽 |
| 传感器 | 流量、压力、功率、温度，带时间戳 |
| 安全层 | 硬件急停、独立保护，不依赖 Poieweave |
| 日志 | 原始传感器与执行记录，可离线审计 |

## 3. 必须预先声明的假设

- 设备退化模型与真实退化速率的差异
- 传感器精度、漂移与失效模式
- 维修动作的实际时长分布
- 安全联锁与人工接管策略
- 外部供电/供水的可用性边界

## 4. 验收证据清单

1. 试验台配置与校准记录
2. 原始传感器/执行日志（不可只保留汇总）
3. 计划与实际动作的差异
4. 故障注入记录（泵、电源、传感器、通信）
5. 人工接管与急停演练记录
6. 能耗/水量/备件消耗账本
7. 独立第三方复核意见
8. 失败与异常清单，而不是只列成功案例

## 5. 判定规则

- 任何安全联锁失效：不通过
- 任何未记录的故障注入：证据不足
- 计划与实际显著偏离且未解释：不通过
- 只在模型内成立：仍为模型级结论，不能升级为物理验收

## 6. 当前结论

M9/M10 未执行。所有 S1–S4 结果都不能替代物理验收；在具备试验台、安全评审与独立复核之前，Poieweave 不应声称工业自主能力。
