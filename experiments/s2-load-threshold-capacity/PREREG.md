# S2 Load Threshold vs Capacity — pre-registration

- Experiment ID: `s2-load-threshold-capacity`
- Date: 2026-11-14
- Status: completed; switch invariant to capacity
- Scope: Base-08, capacities 100–300 kWh.

## Question

Does battery capacity shift the 2.6 kW material-to-energy switch?

## Method

For capacities 100/200/300 kWh, sweep load 2.0–4.0 kW in 0.1 steps and record
the first energy-limited load.

Prediction: larger capacity may raise the switch if it extends storage.

## Limitation

One model/schedule; 0.1 kW resolution.
