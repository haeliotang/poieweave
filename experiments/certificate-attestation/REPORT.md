# Certificate Attestation Plumbing — report

- Date: 2026-11-14
- Status: signing/verification and tamper detection work
- Runner: `python3 experiments/certificate-attestation/attest.py`
- Output: [expected.txt](expected.txt)

## 1. Result

```text
attestation=ok
```

## 2. Findings

- An ephemeral RSA key signs `SHA-256(bundle.json)`.
- The clean signature verifies.
- Replacing the digest with a tampered value makes the same signature fail.

## 3. Significance

- This establishes the detached-signature plumbing for a future trust anchor.
- It deliberately does not claim third-party attestation or a secure key store.

## 4. Limits

- Ephemeral key generated by the test; no persistent identity or trust root.
- Signs only the bundle digest, not the model files directly (the bundle binds
  those separately).
